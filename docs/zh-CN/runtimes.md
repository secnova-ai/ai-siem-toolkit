# 选择工具类型

| 需求 | 类型 | 能力边界 |
|---|---|---|
| 简单 HTTP 调用、参数及响应映射 | CEL | 仅支持文档列出的表达式环境和函数 |
| 签名、复杂解析、有界的多步骤请求 | Go WASM | WASI 沙箱、宿主 HTTP、16 MiB 内存、30 秒执行上限 |
| 已有 MCP、持久会话、后台处理 | MCP | 服务在工具包外运行，自行管理状态 |

CEL 不是 JavaScript/Python，不能编造 HMAC、任意网络、持久变量或会话函数。支持的表达式无法完成需求时，使用 WASM。WASM 也不能任意打开 socket 或执行本机程序，HTTP 必须通过 SDK 访问宿主能力。超出沙箱约束的功能应放入外部服务，可通过 MCP 接入。

每次 CEL/WASM 调用重新获得参数和凭证。“登录工具”不会为后续工具建立共享会话。平台管理的 OAuth 是独立的凭证能力，不是自定义代码通用的状态存储。

v0.1 不包含 builtin、旧版 Dify Provider 开发、OpenAPI 转换、MCP 服务部署、自动上传和市场发布。
