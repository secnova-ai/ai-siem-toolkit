# Examples / 示例

| Project | Demonstrates |
|---|---|
| [cel-health](cel-health/README.md) | CEL health request, auth rejection, invalid input and malformed JSON tests |
| [cel-search](cel-search/README.md) | Nested parameters, exact JSON body and read-only POST |
| [wasm-health](wasm-health/README.md) | Go WASM HTTP SDK, compile and mocked execution |
| [mcp-discovery](mcp-discovery/README.md) | Dynamic MCP provider with no static tool YAML |
| [mcp-static](mcp-static/README.md) | Fixed tool name and input schema for a remote MCP server |

所有接口和凭证均为教学示例，不代表某个真实厂商的可用 API。默认测试使用模拟响应。改成真实接口后再自行选择是否进行 live 联调。
